# Aturan Workspace Umroh by Bilal

Berlaku untuk semua pekerjaan Hermes di workspace ini.

## Dokumentasi wajib

- Baca `Obsidian/README.md` sebelum memulai pekerjaan yang berkaitan dengan workspace ini.
- `Obsidian/` adalah pusat dokumentasi dan wiki Umroh by Bilal.
- Setelah pekerjaan bermakna selesai, buat atau perbarui catatan Markdown yang relevan di `Obsidian/`.
- Catat perubahan nyata, verifikasi, kendala, keputusan, dan tindak lanjut.
- Perbarui catatan kanonis sebelum membuat catatan baru agar tidak terjadi duplikasi.

## Aturan file

- Folder `Obsidian/` hanya berisi file Markdown.
- Jangan menyimpan password, token, API key, passphrase, private key, cookie, atau credential di workspace atau dokumentasi.
- Jangan menghapus atau menimpa catatan manual tanpa alasan yang jelas dan verifikasi.
- Gunakan penulisan idempotent dan pertahankan riwayat perubahan penting.

## Aturan bot dan scheduled jobs

- Semua bot, cron job, webhook, automation, dan agent AI latar belakang wajib menulis hasil bermakna ke catatan Markdown di `Obsidian/`.
- Job berkala harus memperbarui log kanonis per job, bukan membuat file baru pada setiap eksekusi.
- Catat waktu, nama job, status, sumber, hasil, verifikasi, error yang disensor, dan tindak lanjut.
- Gunakan debounce, interval minimum, hash, atau ringkasan untuk mencegah spam.
- Jangan menimpa perubahan manusia; jika terjadi konflik, dokumentasikan dan berhenti dari operasi berisiko.
- Operasi tulis harus atomik bila memungkinkan.

## Verifikasi

Jangan menyatakan pekerjaan selesai tanpa output tool atau pemeriksaan nyata. Jika gagal, jelaskan kegagalan dan dokumentasikan pada `Obsidian/` tanpa menyalin rahasia.
